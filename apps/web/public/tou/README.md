# Terms of Unbeing — optional page art

The dedicated page at `/books/terms-of-unbeing` works fully **without** these
images (they hide gracefully if absent). Drop any of them here to have them
appear. Use the generation prompts from the spec. White/neutral backgrounds
work best against the near-black page.

| File | Where it appears | Prompt (short) |
| --- | --- | --- |
| `building.png` | faint layer behind the hero cover | Nine-story white-stone & black-marble Faust Luxury Residences, brass doors, art deco, subtly impossible angles, griffin crest |
| `gideon.png` | Gideon Cross character card | 41-year-old former Navy corpsman, worn civilian clothes, brass Zippo, immaculate-but-wrong art deco apartment, 43.2% display |
| `arya.png` | Arya character card | Fawn-colored dog, alert, protective, polished black-marble corridor, 6:17 display, watching something off-frame |
| `azrael.png` | Azrael Faust character card | Rail-thin proprietor, charcoal suit, silver fountain pen, windowless leasing office, administrative & predatory |
| `beatrice.png` | Beatrice Hall character card | Dark curly hair, coffee cart outside a severe luxury residence, hidden archive of coffee-stained ledgers |

Filenames must match exactly (lowercase `.png`). The griffin crest is drawn in
SVG in the page itself, so no crest image is required.
